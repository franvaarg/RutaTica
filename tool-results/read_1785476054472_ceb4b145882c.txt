   571→### Best Route Algorithm (/api/best-route)
   572→1. Find nearest origin/destination stops within 1km using bounding box + haversine
   573→2. Find direct routes via StopRoute intersection (routes serving both origin and destination stops)
   574→3. For each direct route: find next trip after departAfter, compute travel time, walking distances, fare
   575→4. If <3 direct routes found: search 1-transfer routes via common intermediate stops (max 20 candidates evaluated)
   576→5. Score all options using normalized weighted scoring (configurable weights)
   577→6. Return top 5 sorted by score ascending (lower = better)
