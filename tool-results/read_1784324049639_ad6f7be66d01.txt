   556→### Best Route Algorithm (/api/best-route)
   557→1. Find nearest origin/destination stops within 1km using bounding box + haversine
   558→2. Find direct routes via StopRoute intersection (routes serving both origin and destination stops)
   559→3. For each direct route: find next trip after departAfter, compute travel time, walking distances, fare
   560→4. If <3 direct routes found: search 1-transfer routes via common intermediate stops (max 20 candidates evaluated)
   561→5. Score all options using normalized weighted scoring (configurable weights)
   562→6. Return top 5 sorted by score ascending (lower = better)
